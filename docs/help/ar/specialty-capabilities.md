# التخصص وحدود القدرات

## تخصص الوكالة (كما هو منفّذ)

1. **تحليل مستودع/منتج** → حزم تقارير مع بوابة مراجعة  
2. **عمليات سطح مكتب محدودة** (ملفات، Excel بسيط، لقطات، UIA / xdotool / osascript)  
3. **تنفيذ Level-3** بعد GO + خطة JSON + اختبارات + تراجع  
4. **مهام يومية** داخل Control Plane  
5. **مسودات بريد** عبر SMTP/Resend بموافقات  
6. **تخصيص الفريق** عبر `config/team.json` + لوحة التحكم  

## مصفوفة صادقة

| القدرة | الحالة | من الكود |
| --- | --- | --- |
| مواصفات / خطط / تقارير مراجعة | نعم | مسار المعمارية + LangGraph |
| أتمتة واجهة Windows | نعم على Windows | المرحلة 4 |
| أتمتة واجهة Ubuntu/macOS | نعم (أفضل جهد) | المرحلة 8؛ تحتاج حزم/أذونات |
| نماذج لكل دور + خريطة هجين حية | نعم | المرحلة 8 |
| تخصيص المسار بدون كود | نعم | إعداد الفريق — حلقة المراجعة وGO ثابتة |
| صدفة عشوائية / تثبيت حزم النظام | لا | قائمة بيضاء فقط |
| سحابة بلا مفتاح أو ميزانية | لا | يحتاج مفتاحاً + سقفاً متبقياً |

## حدود الأدوار (مختصر)

- المخطّطون: تقارير فقط — لا كود عميل بدون GO  
- المدقق/المُتحقق: قراءة + تقارير  
- المنفّذ: أدوات واسعة لكن **يتطلب GO**  
- المشغّل: عمليات آمنة + سطح مكتب بموافقات
