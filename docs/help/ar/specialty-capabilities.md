# التخصص وحدود القدرات

## تخصص الوكالة (كما هو منفّذ)

Sam-Harness وكالة هجينة لـ:

1. **تحليل مستودع / منتج** → حزمة تقارير مرقّمة (استراتيجية، تدقيق، معمارية، مساعدة-مواصفة، تسويق، تحقق) مع بوابة مراجعة  
2. **تشغيل سطح مكتب محدود** على مسارات مسموحة (ملفات، Excel بسيط، لقطات على ويندوز، UIA على ويندوز)  
3. **تنفيذ كود Level-3** فقط بعد تفويض المالك (GO) وخطة JSON واختبارات + تراجع  
4. **عمليات يومية مجدولة** داخل Control Plane (التكة الافتراضية تسجّل؛ التشغيل الكامل عبر Run)  
5. **اتصالات مسودة** بريد SMTP/Resend مع موافقات صارمة  

ليست «مطور تطبيقات كامل الخدمة» ولا «أتمتة سطح مكتب عامة لكل أنظمة التشغيل».

## مصفوفة صادقة

| القدرة | الحالة | التوضيح من الكود |
| --- | --- | --- |
| كتابة مواصفات / خطط / تقارير مراجعة | نعم | مسار architecture + LangGraph |
| بناء صفحة ويب من الصفر كمنتج | جزئي | يمكن `write_file` / L3 داخل مستودع مفوَّض — **ليس** منشئ صفحات |
| إنشاء تطبيق كامل (واجهة+خادم+نشر) | جزئي / محدود | تخطيط نعم؛ التنفيذ يحتاج GO + خطة + صدفة مقيدة جداً |
| تعديل ملفات في مساحة العمل المسموحة | نعم | operator / implementer حسب الدور |
| إنشاء Excel/CSV بسيط | نعم | `write_excel` (SpreadsheetML / CSV) |
| أتمتة واجهة ويندوز (Notepad وغيرها عبر UIA) | نعم على Windows | Phase 4؛ اختبار تكامل Notepad في CI ويندوز |
| أتمتة سطح مكتب Ubuntu/macOS | لا | backends = stub ترمي «not implemented» |
| إرسال بريد حقيقي | جزئي | SMTP/Resend منفّذان؛ افتراضي dry-run حتى ضبط SMTP + موافقات |
| جدولة مهام يومية | نعم | Daily Ops؛ التكة الافتراضية دفتر ملاحظات لا وكيل كامل |
| MCP لأدوات خارجية | نعم | بعد `mcp.json` |
| عزل كود `run_node_sandbox` | نعم | عملية فرعية؛ Docker اختياري `SAM_SANDBOX_DOCKER=1` |
| صدفة عشوائية / تثبيت حزم النظام | لا | قائمة بيضاء: `dir`/`type`/`echo`/`where`/`Get-*` فقط |
| سحابة بلا مفتاح أو بلا ميزانية | لا | يحتاج `OLLAMA_API_KEY` + سقف متبقي |
| نظام مساعدة داخل المنتج (هذا الدليل) | نعم | `docs/help` + CLI/API/UI/تصدير |
| دور help في الحزمة فقط `help-system-spec.md` | نعم | مخرج تخطيط بعد APPROVED — مختلف عن مساعدة المنتج |

## حدود الأدوار (مختصر)

- المخطِّطون (strategist/architect/help/marketer): تقارير في مساحة العمل — **لا** كود عميل بلا GO  
- auditor/verifier: قراءة + تقارير تدقيق/تحقق  
- implementer: كامل الأدوات تقريباً لكن **يتطلب GO**  
- operator: عمليات آمنة على المسارات المسموحة + سطح المكتب مع موافقات
