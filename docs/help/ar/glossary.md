# قاموس المصطلحات

| المصطلح | المعنى في الكود |
| --- | --- |
| L1 / operational | حلقة CEO + أدوات operator للمهام على الجهاز |
| L2 / architecture swarm | سرب خطي تراثي (`AGENCY_MODE=0`) |
| Agency / LangGraph | المسار الافتراضي للتحليل (`AGENCY_MODE=1`) مع حلقة مراجعة |
| Level-3 / implement | تطبيق خطة JSON على مستودع بعد GO |
| Go/No-Go | تفويض مالك قبل لمس كود العميل |
| Hybrid | اختيار local/cloud/auto مع سقف تكلفة |
| Evidence Scout | مسح المستهدف قبل التدقيق |
| Goal fidelity | بوابة صلبة بعد موافقة المدقق في مسار LangGraph |
| Control Plane | خادم UI/API على المنفذ 8787 |
| SAM_OUTPUT_HOME | جذر مخرجات الوكيل |
| MCP | Model Context Protocol — أدوات خارجية عبر `mcp.json` |
| HITL | موافقة بشرية في الحلقة |
| Doctor | فحوصات صحة التثبيت المحلية |
| Planned / not implemented | قدرة في الوثائق/الأنواع دون تنفيذ تشغيلي كامل |
