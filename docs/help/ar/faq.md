# أسئلة شائعة

**هل تبني مواقع؟**  
جزئياً: تكتب ملفات/خطط ويمكنها تنفيذ رقعات بعد GO — ليست منشئ مواقع مرئي.

**هل تعمل على أوبونتو يومياً؟**  
ملفات، مجدول، بريد، MCP، نماذج — نعم. نقر واجهات رسومية — لا (stub).

**هل تحتاج إنترنت؟**  
للسحابة المدفوعة نعم. المسار المحلي عبر Ollama يمكن أن يعمل دون سحابة.

**أين التقارير؟**  
`SAM_OUTPUT_HOME` → عادةً `Documents/Sam-Harness`، والحزم المرقّمة تحت التقارير/docs حسب المسار.

**كيف أغيّر اللغة؟**  
`SAM_LOCALE=ar|en` أو مبدّل اللغة في رأس الواجهة.

**ما الفرق بين دور help ومساعدة المنتج؟**  
دور `help` يكتب `help-system-spec.md` داخل حزمة التحليل. مساعدة المنتج هي `docs/help` + `pnpm run help` + تبويب الواجهة.

**هل يمكن تجاوز سقف $0.50؟**  
لا تلقائياً. ارفع السقف من ملف الهجين إن رغبت؛ النظام يرفض الشحنات التي تتجاوز السقف.
