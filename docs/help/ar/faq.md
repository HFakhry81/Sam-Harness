# أسئلة شائعة

**هل يبني مواقع؟**  
جزئياً: يكتب ملفات/خططاً ويطبّق رقعاً بعد GO — ليس منشئ صفحات مرئياً.

**هل يؤدّي مهام Ubuntu اليومية؟**  
نعم للملفات والمجدول والبريد وMCP والنماذج والصدفة المسموحة والواجهة عند تثبيت `wmctrl`/`xdotool`/`scrot` (أو مكافئات Wayland). انظر التحكم بالجهاز.

**هل يحتاج إنترنت؟**  
للسحابة المدفوعة نعم. المسار المحلي عبر Ollama يمكن بلا سحابة.

**أين التقارير؟**  
تحت `SAM_OUTPUT_HOME` — عادةً `Documents/Sam-Harness`.

**كيف أغيّر اللغة؟**  
`SAM_LOCALE=ar|en` أو مبدّل اللغة في الواجهة.

**الفرق بين دور help ومساعدة المنتج؟**  
الدور يكتب `help-system-spec.md` داخل الحزمة. مساعدة المنتج هي `docs/help` + `pnpm run help` + تبويب الواجهة.

**لماذا شغّلت التحية الوكالة كاملة؟**  
سابقاً نعم. الآن التحيات والأسئلة البسيطة تأخذ مسار **سريع** (نموذج محلي). فعّل **تشغيل كوكالة كاملة** لإجبار المسار. انظر [`quick-path`](quick-path.md).

**هل يتجاوز سقف ٠٫٥٠ دولار؟**  
ليس تلقائياً. ارفع السقف من ملف الهجين إن أردت؛ النظام يرفض ما يتجاوز السقف.

**كيف أغيّر نموذج دور؟**  
`config/team.json` أو تبويب الفريق أو `SAM_ROLE_<ROLE>_MODEL`.

**هل أعيد ترتيب المتخصصين؟**  
نعم — تبويب الفريق / `POST /api/team/pipeline`. حلقة المراجعة وبوابة GO تبقى ثابتة.
