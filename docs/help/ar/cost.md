# التكلفة والميزانية

- السقف اليومي الافتراضي للسحابة: **$0.50** لكل tenant  
- `$0` = منع السحابة بالكامل  
- المحاسبة دقيقة لكل تشغيل/يوم؛ التخزين المؤقت للبرومبت في SQLite يقلّل التكرار (`SAM_CACHE_ENABLED`)  
- قرب السقف → تدهور لمحلي/مجاني (انظر [`hybrid-mode`](hybrid-mode.md))  
- رفع السقف: تبويب الهجين في الواجهة أو تحديث ملف الهجين  

عرض الحالة: `GET /api/cost-usage` وشريط التكلفة في الواجهة.

الوثيقة التفصيلية للكود: `docs/PHASE5_NEAR_ZERO_COST.md`.
