# مسار الرد السريع

يصنّف Sam-Harness كل رسالة من لوحة التحكم **قبل** تشغيل وكالة LangGraph الكاملة.

## المسارات

| المسار | متى | ماذا يعمل |
| --- | --- | --- |
| **سريع** | تحية / دردشة قصيرة، سؤال بسيط | استدعاء واحد لنموذج Ollama محلي (دور `quick`) |
| **ويب** | «ابحث على النت…»، أخبار / تفاصيل حالية | DuckDuckGo (أو مزوّد بمفتاح) + جلب صفحات + ملخص قصير مع روابط المصادر |
| **وكالة** | كود، ملفات، سطح مكتب، عمل متعدد الخطوات | مسار الوكالة الحالي دون تغيير |

هدف السريع/الويب: أقل من ~10 ثوانٍ. الوكالة تبقى للمهام الحقيقية.

## اللغة

الرد بنفس لغة المستخدم (عربي → عربي). بدون تفريغ حالة النظام.

## النماذج

قابل للضبط في `config/team.json` بدور `quick` (افتراضي محلي `qwen2.5:1.5b`). تجاوز عبر:

- `SAM_ROLE_QUICK_MODEL`
- `SAM_ROLE_QUICK_CLOUD_MODEL`

إن تعذّر النموذج المفضّل يُستخدم أرخص نموذج محلي / CEO.

## بحث الويب

الافتراضي: DuckDuckGo HTML (بدون مفتاح). اختياري عبر `.env`:

- `SAM_WEB_SEARCH_PROVIDER=duckduckgo|tavily|brave|searxng`
- `TAVILY_API_KEY` / `BRAVE_API_KEY` / `SEARXNG_URL`

يحترم سقف التكلفة، `SAM_ALLOW_NETWORK_EGRESS`، وموافقة الشبكة الاختيارية، وسجل التدقيق. تُسجَّل التكلفة في دفتر الاستخدام.

## إجبار الوكالة الكاملة

في لوحة التحكم فعّل **تشغيل كوكالة كاملة** (أو `FORCE_AGENCY=1` / `--force-agency` في الطرفية). يظهر في سجل الجلسة شارة **سريع / ويب / وكالة** لكل تشغيل.
