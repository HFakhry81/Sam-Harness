# موجّه النية (محادثة / بحث / مهمة / معقد)

يصنّف Sam-Harness **كل** رسالة **قبل** أي مسار وكالة أو تشغيل — زر إرسال في لوحة التحكم ومدخل CLI يستخدمان نفس الموجّه.

## المسارات

| المسار | متى | ماذا يعمل |
| --- | --- | --- |
| **محادثة (chat)** | تحية، دردشة، تعريف بالاسم، سؤال بسيط | رد قصير بلغة المستخدم. **بدون** `task.ts` و**بدون** حزم تقارير و**بدون** ملفات. |
| **بحث (research)** | يحتاج بحثاً / «ابحث على النت» | بحث + إجابة موجزة مع مصادر. ملف ملاحظة اختياري واحد تحت `documents/research-notes/`. |
| **مهمة (task)** | أمر/إجراء سطح مكتب واحد | حلقة CEO التشغيلية. |
| **معقد (complex)** | مسارات + افحص/ابني/صلح/حلل، معمار، متعدد الخطوات | وكالة كاملة مع حزم تقارير. |
| **توضيح (clarify)** | غير متأكد بين محادثة ومهمة | سؤال توضيحي بسطر واحد — دون تشغيل الوكالة. |

قواعد حتمية أولاً (تحيات عربية/إنجليزية، أنماط أسئلة، مسارات + أفعال). إن بقي الغموض: نموذج محلي صغير (**≤3B**). عند الشك يسأل بدلاً من تشغيل الوكالة.

يحترم سقف التكلفة اليومي **0.50$**.

## إجبار الوكالة الكاملة

خانة **تشغيل كوكالة كاملة** أو `--force-agency` / `FORCE_AGENCY=1`.

## الواجهة

عرض محادثة: قائمة رسائل + حقل إدخال + **إرسال**. ملصق مسار خفيف على الرد. لوحة التقارير للمهام فقط (مطوية افتراضياً). فشل المحادثة لا يظهر **FAILED / task saved for retry**.

## سجل المحادثة

تحت `SAM_OUTPUT_HOME/conversations/` (عادةً `~/Documents/Sam-Harness/conversations/`).
