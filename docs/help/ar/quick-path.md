# موجّه النية (محادثة / بحث / مهمة / معقد)

يصنّف Sam-Harness **كل** رسالة **قبل** أي مسار وكالة أو تشغيل — زر إرسال في لوحة التحكم ومدخل CLI يستخدمان نفس الموجّه.

## المسارات

| المسار | متى | ماذا يعمل |
| --- | --- | --- |
| **محادثة (chat)** | تحية، دردشة، تعريف بالاسم، سؤال بسيط | رد قصير بلغة المستخدم. **بدون** `task.ts` و**بدون** حزم تقارير و**بدون** ملفات. |
| **بحث (research)** | يحتاج بحثاً / «ابحث على النت» | بحث + إجابة موجزة بمصادر تظهر داخل المحادثة. لا تنشئ محادثة Control Plane ملفات ملاحظات. |
| **مهمة (task)** | أمر/إجراء سطح مكتب واحد | حلقة CEO التشغيلية. |
| **معقد (complex)** | مسارات + افحص/ابني/صلح/حلل، معمار، متعدد الخطوات | وكالة كاملة مع حزم تقارير. |
| **توضيح (clarify)** | غير متأكد بين محادثة ومهمة | سؤال توضيحي بسطر واحد — دون تشغيل الوكالة. |

قواعد حتمية أولاً (تحيات عربية/إنجليزية، أنماط أسئلة، مسارات + أفعال). إن بقي الغموض: نموذج محلي صغير (**≤3B**). عند الشك يسأل بدلاً من تشغيل الوكالة.

يحترم سقف التكلفة اليومي **0.50$**.

## إجبار الوكالة الكاملة

خانة **تشغيل كوكالة كاملة** أو `--force-agency` / `FORCE_AGENCY=1`.

## الواجهة

عرض محادثة: قائمة رسائل + حقل إدخال + **إرسال**. ملصق مسار خفيف على الرد. لوحة التقارير للمهام فقط (مطوية افتراضياً). فشل المحادثة لا يظهر **FAILED / task saved for retry**.

## سجل المحادثة

يُحفظ سجل المحادثات والحقائق التي تطلب حفظها صراحةً في قاعدة بيانات المستأجر، دون ملفات نصية لكل محادثة. يُسترجع سياق محدود من المحادثات السابقة. استخدم `تذكّر: ...` لحفظ معلومة دائمة.

## النماذج

اختر **تلقائي** أو **محلي** أو **سحابي** من محرر المحادثة. يتبع التلقائي إعدادات دور `quick`، ويتطلب السحابي مفتاح مزود ويلتزم بسقف التكلفة اليومي.

يمكن للمحادثة استخدام أدوات القراءة فقط بشكل متتابع: `list_dir` و`read_file` و`search_code` (حتى 8 استدعاءات في الرسالة). تبقى الكتابة والأوامر وحذف الملفات ضمن مسار المهام وموافقاته. وإذا طلب النموذج السحابي أداةً للوصول إلى ملفات مساحة العمل، تُرسل نتائج الأداة إلى نموذج محلي للمتابعة فقط ولا تُرسل محتويات الملفات إلى النموذج السحابي.

عنوان Ollama المحلي الافتراضي هو `http://127.0.0.1:11434` ويمكن تغييره عبر `SAM_LOCAL_BASE_URL`. عند ظهور خطأ اتصال، شغّل Ollama وتحقق من النموذج المحدد عبر `ollama list`، وثبّت النموذج المفقود باستخدام `ollama pull <model>`.

تستخدم المحادثة التفاعلية افتراضياً سياقاً بحجم 4K ودفعة من 256 رمزاً واحتفاظاً بالنموذج لمدة 5 دقائق للحد من استهلاك ذاكرة GPU/RAM. يمكن ضبطها عبر `SAM_QUICK_NUM_CTX` و`SAM_QUICK_NUM_BATCH` و`SAM_QUICK_KEEP_ALIVE`؛ وتبقى إعدادات الأدوار الطويلة على `SAM_LOCAL_NUM_CTX` و`SAM_LOCAL_NUM_BATCH`.
