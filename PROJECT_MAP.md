## Architecture Rules
1. **Three-Tier Agent System:**
   - Level-1: Operational agents (task execution)
   - Level-2: Architecture agents (swarm coordination)
   - Level-3: Implementation agents (code generation)

2. **Review Loop Pattern:** Strategist → Auditor → Architect (approval gates)

3. **Delivery OS:** Go/No-Go gates before client code changes

4. **Security Boundaries:**
   - All secrets encrypted at rest
   - PII redaction on logs
   - Access control via role-based permissions

5. **Database Pattern:**
   - SQLite for development/local
   - PostgreSQL for production
   - Drizzle migrations for schema changes

6. **Git Workflow:** staging → main only, protected branches
